Airline Ticket Price Explorer

This application lets you upload an airline flights dataset, clean the data, train multiple machine learning models, and deploy the best one to predict ticket prices for new flight scenarios.

  • Upload a CSV file with flight and ticket price data.
  • Clean and explore the dataset using interactive visualizations.
  • Train multiple models (e.g., Linear Regression, Random Forest, Gradient Boosting).
  • Compare model performance and deploy the best one.
  • Use the deployed model to predict prices for new flights.

Use the navigation at the top to move through the workflow after uploading your data.

Upload Dataset

Upload a CSV file containing airline ticket data. Make sure it includes the required columns (e.g., airline, flight, cities, times, price, etc.).
